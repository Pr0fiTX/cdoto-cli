# 📝 Cdoto

**Cdoto** — это минималистичный, быстрый и легковесный менеджер задач (Todo-list), написанный на чистом языке **C**. Работает прямо из терминала и хранит все задачи в простом текстовом файле `cdoto.txt`. Никаких лишних зависимостей — только вы, терминал и ваш список дел.

---

## ⚡ Особенности

- **Чистый C (C99+):** Без внешних библиотек и фреймворков.
- **Быстрый и компактный:** Идеально подходит для unix-подобных систем.
- **Простое хранение:** Все задачи сохраняются локально в файл `cdoto.txt`.
- **Удобное управление:** Поддерживает создание, просмотр, выполнение и сброс статуса задач через флаги командной строки.

---

## 🛠️ Сборка и установка

Для компиляции приложения вам понадобится любой стандартный компилятор C (например, `gcc` или `clang`) и утилита `make` (или запуск команды вручную).

Клонируйте репозиторий и скомпилируйте проект:

```bash
# Клонирование репозитория
git clone https://github.com/Pr0fiTX/cdoto-cli.git
cd cdoto-cli

# Компиляция с помощью GCC
gcc -O3 cdoto.c -o cdoto
```

При желании вы можете переместить скомпилированный бинарник в директорию, доступную в вашей переменной окружения `PATH` (например, `/usr/local/bin`), чтобы запускать `cdoto` из любого места.

## 🚀 Использование

При запуске без аргументов приложение выводит список всех существующих задач.

```bash
./cdoto
```

### Доступные флаги и команды

| Команда / Флаг | Описание | Пример |
| :--- | :--- | :--- |
| *(без аргументов)* | Показать список всех задач | `./cdoto` |
| `-h` | Показать справку и меню помощи | `./cdoto -h` |
| `-c TITLE [DESC]` | Создать новую задачу с заголовком и опциональным описанием | `./cdoto -c "Купить молоко" "В магазине за углом"` |
| `-d ID` | Пометить задачу с указанным ID как **выполненную** | `./cdoto -d 1` |
| `-d -ID` | Пометить задачу с отрицательным ID как **активную** (вернуть в работу) | `./cdoto -d -1` |

---

## 📂 Формат хранения данных

Задачи сохраняются в файл `cdoto.txt` в корневой директории приложения в следующем формате:
```text
ID^Заголовок^Описание^Статус
```
